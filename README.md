# ☕ ames coffee

A little walk-up coffee window on McLennan St, Albion, Brisbane — no dining room, no table service, just a hatch, a queue on the footpath, and Rooky the border collie usually out front before you are.

Espresso, iced drinks, first-harvest Japanese matcha, and seasonal juice, open every day from 6am. Rated 5.0★ on Google from 45 reviews.

This repo is the marketing site: one page covering the menu, gallery, story and how to find the place.

## 🛠️ Tech stack

- ⚛️ [Next.js](https://nextjs.org/) (App Router) + TypeScript
- 🎨 [Tailwind CSS](https://tailwindcss.com/) v4
- 🎠 [Embla Carousel](https://www.embla-carousel.com/) for the photo gallery
